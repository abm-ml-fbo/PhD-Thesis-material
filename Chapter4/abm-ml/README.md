 # ML-ABM model guide

This folder contains everything required to:
1. Train the CatBoost machine learning model
2. Run the agent-based model (ABM) that uses the trained model.

All files are self-contained. Simply prepare a Python environment, open JupyterLab, and run the two notebooks.

---

## 1. Environment Setup

Recommended: **Python 3.10 or 3.11**

---

## 2. File Overview

| File | Purpose |
|------|---------|
| **1_train_ml_model.ipynb** | Trains the CatBoost model and saves final artifacts |
| **2_ABM.ipynb** | Runs the ABM simulation using the trained model |
| **3_final_SA.ipynb** | Runs the sensitivity analsis of the ABM |
| **ml_inference.py** | Loads the trained model and performs predictions (-1 / 0 / +1) |
| **final_catboost_model.cbm** | Trained CatBoost model (generated by 1_train_ml_model.ipynb) |
| **final_catboost_model.meta.json** | Metadata: feature order + label mapping (generated by 1_train_ml_model.ipynb) |
| **ml_train_dataset.xlsx** | ML training data |
| **init_ABM_dataset.xlsx** | ABM initialization data |
| **requirements.txt** | Packages required to run the bundle |

---

## 3. Usage Steps

### Step 1 — Train the ML Model
1. Open **`1_train_ml_model.ipynb`** in JupyterLab.
2. Run all cells.
3. The notebook will automatically generate/refresh:
   - `final_catboost_model.cbm`
   - `final_catboost_model.meta.json`

---

### Step 2 — Run the ABM Simulation
1. Open **`2_ABM.ipynb`**.
2. Run all cells from top to bottom.
3. The notebook will:
   - Load input Excel data
   - Load the trained model through `ml_inference.py`
   - Run the agent-based simulation
   - Display results and visualizations within the notebook

---

### Step 3 — Run the Sensitivity analysis of ABM 
1. Open **`3_final_SA.ipynb`**.
2. Run all cells from top to bottom.
3. The notebook will:
   - Run the sensitivity analysis
   - Display results and figures

---
